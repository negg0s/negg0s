# NEGG0

Systems programming, Linux internals, compilers, and low-latency audio stack.

### Stack

- Languages: C++20, Python, C, Bash, JavaScript
- Systems: Linux (Arch, Fedora, Ubuntu, SteamOS), Windows / Wine / Proton internals
- Audio: PipeWire (SPA DSP nodes), OpenAL Soft (EFX, HRTF, 3D Audio), DirectSound3D shim
- Tooling: CMake, Clang, GCC, GDB, Valgrind, AddressSanitizer, libFuzzer, systemd, Git, Docker

### Projects

- [zenith-gaming-daemon](https://github.com/negg0s/zenith-gaming-daemon): Linux game session optimizer daemon (C++20, systemd, cgroups v2, Netlink connector).
- [eax-native](https://github.com/negg0s/eax-native): Native DirectSound3D and EAX 1.0/2.0 stack for Wine/Proton games via OpenAL Soft and PipeWire.
- [VeloC](https://github.com/negg0s/VeloC): Experimental C++ dialect and source-to-source compiler in Python targeting Clang.
- [chess-ai](https://github.com/negg0s/chess-ai): Lichess bot pairing Stockfish with experimental ResNet policy-value net and computer vision.
- [discord-stuff](https://github.com/negg0s/discord-stuff): Userscripts for Vencord.
